What is a Transformer?

The Transformer replaces recurrent neural networks with self-attention — a mechanism that lets every token directly look at every other token. This enables parallel training and long-range dependencies without vanishing gradients.

This demo trains a tiny English→French translator on 8 phrase pairs to make the architecture easy to understand. It is not a production LLM.

Paper: Attention Is All You Need

Architecture

Core Math
Attention(Q, K, V) = softmax(QKT / √dk) · V

Scaled Dot-Product: Queries and Keys are dot-producted, scaled by √d_k to prevent softmax saturation, then softmaxed to get attention weights multiplied by Values.

Multi-Head: Run H parallel attention heads on different projection subspaces, concatenate, and project with W_O.

Positional Encoding: Sinusoidal functions added to embeddings so the model knows token order.

Positional Encodings

Sinusoidal encodings inject position information. Each dimension oscillates at a different frequency.

What I Learned
  • Attention replaces recurrence — O(L²) but fully parallelizable on GPU.
  • Scaling by √d_k keeps softmax gradients healthy as dimension grows.
  • Positional encodings are required because attention alone is order-blind.
  • Residual connections + LayerNorm stabilize deep stacks.
  • Teacher forcing trains the decoder with ground-truth prefixes.
